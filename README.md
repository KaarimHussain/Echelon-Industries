# Echelon Industries | Corporate Portfolio

A high-performance, meticulously designed portfolio website serving as the digital storefront for Echelon Industries. This project emphasizes a minimalist, modern aesthetic while delivering a seamless and responsive user experience.

---

## 🚀 Overview

The Echelon Industries portfolio is engineered to highlight core services, company vision, and featured projects. The UI architecture is built around **"Linear" modernist aesthetics**, utilizing structured **bento grids** and a **high-contrast dark theme** with deep crimson accents to maintain a sleek, professional corporate identity.

---

## ⚙️ Tech Stack

This frontend is built for speed, scalability, and maintainability:

* **Framework:** React + TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **UI Components:** Shadcn UI
* **Integration-Ready:** Architecture designed to easily consume APIs from .NET or Node.js backends

---

## ✨ Key Features

* **Modernist UI/UX:** Clean, distraction-free interface prioritizing content readability
* **Bento Grid Layouts:** Organized, modular presentation of company assets and information
* **High-Contrast Dark Theme:** Polished aesthetic with custom red/crimson accents
* **Fully Responsive:** Optimized across all breakpoints, from mobile to ultra-wide displays
* **Type-Safe:** Strict TypeScript configuration for robust development

## 💻 Getting Started

Follow these steps to set up the development environment locally.

### Prerequisites

* Node.js (v18+ recommended)
* npm or pnpm

### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/KaarimHussain/Echelon-Industries.git
```

2. **Navigate to the directory:**

```bash
cd Echelon-Industries
```

3. **Install dependencies:**

```bash
npm install
```

4. **Start the development server:**

```bash
npm run dev
```

---

## 📂 Project Structure

* `/src` – Core application logic, React components, and routing views
* `/public` – Static assets, images, and brand icons
* `components.json` – Shadcn UI module configuration
* `tailwind.config.js` – Design system, custom theme overrides, and color palettes
* `vite.config.ts` – Build and development server configuration
